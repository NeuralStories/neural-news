# Matriz para decidir la unificación

**Criterio:** «Operativo» significa comprobado en la aplicación publicada en modo demo o mediante una acción local segura. «Parcial» significa que hay una parte funcional pero falta el recorrido completo. «Simulado» significa contenido determinista/fixture o activo de prueba. «No validado» indica adaptador escrito sin prueba con proveedor real. Las decisiones de la última columna son propuestas para revisar, no cambios ejecutados.

## Código aprovechable de inmediato

La API editorial, estados versionados, contratos, cola y render FFmpeg pueden permanecer. De Studio pueden recuperarse el analizador de guion, tipos de escena, catálogo de movimientos, modelo de referencias, perfil canónico y editor de plan. Las llamadas `Flow.generate.*` y los activos de ejemplo requieren validación; no se consideran funcionalidad de producción comprobada. La redacción duplicada de Studio y el `iframe` son candidatos a eliminación **después** de migrar su utilidad y decidir la arquitectura con el propietario.
